# Archive Directory

> ⚠️ **DO NOT COMPILE OR IMPORT**
>
> This folder contains archived code, old scripts, and deprecated files.
> These files are kept for historical reference only.

## Contents

- **dead_code/** - Code that is no longer used in the application
- **scripts/** - Old utility scripts moved from project root
- **docs/** - Archived documentation (phase completion files, old plans)
- **temp/** - Temporary files that were at project root

## Why Archived?

These files were identified during a codebase cleanup audit and moved here because:

1. They are no longer actively used
2. They duplicate functionality in the main codebase
3. They are historical documentation no longer relevant to current development
4. They are temporary files that should not be in version control

## Safe to Delete?

Yes, this entire folder can be safely deleted if disk space is a concern.
All important functionality has been preserved in the main codebase.
